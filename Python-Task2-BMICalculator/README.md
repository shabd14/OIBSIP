# BMI Calculator

A simple command line Python program that calculates your BMI using your weight in kg and height in meters/centimeters.

Features:

- Can take height in either meters (e.g. 1.70) or centimeters (e.g. 170).

- Input validation, if an incorrect value is entered it will prompt the user to re-enter.

- Rounded BMI to 2 decimal places.

- Gives a category based on the BMI ranges.

Requirements:

- Python 3

- No external packages required.

How to run

Open a terminal within this folder and type in:

```bash

python main.py

```

If python3 is used on your system:

```bash

python3 main.py

```

Example:

```text

BMI Calculator

Enter your weight in kg: 68

Enter your height in m (e.g 1.70) or cm (e.g 170): 170

Your BMI is 23.53

You are in the Normal category.

Note: BMI is a general indicator and is not a medical diagnosis.

```

The result will vary depending on what you input.

Formula:

```text

BMI = Weight (kg) / (Height (m) x Height (m))

```

Underweight - Less than 18.5

Normal - 18.5 to under 25

Overweight - 25 to under 30

Obese - 30 and above
