# OIBSIP - Python Programming

This repository is for the Python Programming internship tasks. Each project has its own folder, source code, and run instructions.

## Projects

1. [BMI Calculator](Python-Task2-BMICalculator/README.md) - a command-line BMI calculator with input checks and category labels.
2. [Random Password Generator](Python-Task3-RandomPasswordGenerator/README.md) - a command-line password generator with character-type choices.
3. [Chat Application](Python-Task5-ChatApplication/README.md) - a two-user command-line chat using Python sockets and threads.

Before submitting, run each project locally, add screenshots of the actual program, and record a working demo.
